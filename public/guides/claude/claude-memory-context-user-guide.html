Memory & Context Management

Understand how Claude remembers, what it forgets, and how to give it the right information at the right time — every session.

1

What is Memory & Context?

Claude doesn't have persistent memory the way a human colleague does. Each conversation is a fresh start — unless you actively set it up otherwise. Understanding how Claude's memory works lets you get consistent, informed responses without repeating yourself every time.

There are two concepts to separate: context (what Claude can see right now, in this conversation) and memory (information that persists across sessions). Claude handles both very differently.

Session

In-Conversation Context

Everything in your current conversation — messages, files, instructions. Exists only for this session.

Projects

Project Memory

Files and instructions you pin inside a Claude Project. Automatically included in every chat within that project.

System

Custom Instructions

Persistent preferences and behaviours you set once. Claude applies them to every conversation by default.

Why this matters:

Most people lose time re-explaining context at the start of every session. Master these three layers and Claude will feel like it actually knows you and your work.

2

The Context Window Explained

Claude processes everything — your messages, its replies, uploaded files, instructions — inside a context window: a fixed-size working memory measured in tokens (roughly 0.75 words each). Claude's context window is very large, but it is finite.

What counts toward context?

📝 Messages

Every message you send and every reply Claude gives is included. Long back-and-forth threads consume tokens fast.

📎 Files & Uploads

PDFs, Word docs, images, data files — all converted to text tokens when you upload them.

⚙️ System Prompt

Your Custom Instructions and Project instructions run in every conversation, consuming tokens before you type a word.

🔁 Project Files

Any files pinned to your Project are loaded into context automatically at the start of every conversation.

When you approach the context limit:

Claude will tell you the conversation is getting long. Start a fresh conversation and paste in just the essential context — don't try to compress an old one.

3

Projects & Persistent Files

Claude Projects are the closest thing to true long-term memory. A Project lets you pin files and write a set of standing instructions that Claude loads automatically at the start of every conversation in that project.

1

Create a Project

From the Claude sidebar, click New Project. Give it a name that reflects the context — "Client: Acme Corp" or "Marketing Campaigns Q3".

2

Add Project Instructions

Write what Claude should always know: your role, the client, preferred tone, key terminology, constraints. This is your persistent briefing document.

3

Upload Reference Files

Pin documents Claude will reference across sessions — brand guidelines, style guides, SOPs, data dictionaries, stakeholder lists.

4

Start Conversations Inside the Project

Every new chat in this project inherits the instructions and files automatically. No re-pasting required.

Best practice:

Keep project files under 50 pages each. Very long files consume large chunks of context before you even start — summarise or split them when possible.

4

Custom Instructions

Custom Instructions (also called the System Prompt in claude.ai) let you set global preferences that apply to every conversation — not just a specific project. Think of it as your default Claude profile.

What to include in Custom Instructions

🧑 Who you are

"I'm a marketing manager at a B2B SaaS company. I work in content, strategy, and campaign planning."

🎯 How you want responses

"Keep replies concise. Use bullet points for lists. Don't add disclaimers unless I ask for them."

🗣️ Tone preferences

"Write in a direct, professional tone. Avoid corporate jargon. My audience is mid-level managers."

🚫 Standing constraints

"Never suggest I use tools I haven't mentioned. Don't recommend outsourcing unless I bring it up."

Setting Custom Instructions

1

Open Settings

Click your profile icon → Settings → Custom Instructions (or "Default Instructions" depending on your plan).

2

Write Your Instructions

Be specific and use plain language. Claude follows instructions literally — "be brief" is less effective than "limit responses to 150 words unless I ask for more".

3

Test and Refine

Start a fresh conversation and see how Claude behaves. Adjust instructions based on what it gets right or wrong.

Pro tip:

Custom Instructions are global defaults. Project Instructions override them for that project. You can use both in tandem — global for your universal preferences, project-specific for context that only applies to one workstream.

5

Memory Across Sessions

By default, Claude forgets everything when you close a conversation. Projects and Custom Instructions solve this at the structural level — but there are also manual techniques for preserving context across sessions.

The Session Summary Method

At the end of an important work session, ask Claude to produce a summary you can paste into the next conversation to restore context instantly.

End of Session (Today)
You: "Summarise what we've worked on today. Include: decisions made, open questions, next steps, and any context I'll need to continue this work in a future session."
Claude: "Here's your session summary: We drafted three email sequences for the Q3 onboarding flow. Decision: go with Option B subject lines. Open: legal review of the guarantee language. Next: write the follow-up sequence for week 2. Key context: the audience is enterprise buyers, average deal size $50k, primary pain point is implementation risk..."
Next Session (Tomorrow)
You: "Continuing from yesterday. Here's the context: [paste summary]"
Claude: "Got it — picking up from the Q3 onboarding sequences. You're ready to write the week-2 follow-up sequence. Shall I start with the first email, focusing on enterprise buyers worried about implementation risk?"
Save your summaries:

Keep a running "Claude Context" doc in Notion or a text file. Paste the summary in at the start of each session, and ask Claude to update it at the end. You'll never lose work in progress again.

6

Long Documents & Files

Claude can read and reason across entire documents — PDFs, Word docs, CSVs, text files. Knowing how to upload and reference them effectively is key to getting useful analysis.

Uploading Files

1

Use the attachment icon

Click the paperclip or drag the file directly into the chat. Supported: PDF, DOCX, XLSX, CSV, TXT, images, code files.

2

Tell Claude what to do with it

Don't just upload — give a specific instruction. "Read this report and extract the five most surprising findings" works far better than "here's a report".

3

Reference specific sections

If you need Claude to focus, direct it: "Focus only on Section 3 — the competitive analysis." This conserves context and produces sharper output.

File TypeBest UseTips
PDF / DOCXReports, proposals, policiesAsk for summaries or extractions, not full rewrites
CSV / XLSXData analysis, filtering, comparisonsDescribe what insights you need upfront
ImagesCharts, diagrams, screenshotsAsk Claude to describe or interpret — it can read text in images
Code filesReview, debugging, documentationSpecify the language and what you want checked
Text / MarkdownNotes, drafts, transcriptsBest format for fast processing, low token cost
Very long documents:

Files over 100 pages can consume most of your context budget. For large documents, extract the relevant sections first (using a PDF reader or Ctrl+F) and paste just those sections into the chat.

7

Advanced Techniques

The Context Anchor

Open every conversation with a compact context block — 3–5 sentences covering who you are, what project this relates to, and what outcome you need. This anchors Claude even without a project.

Context anchor template:

"I'm a [role] at [organisation]. I'm working on [project/task]. The audience is [audience]. The goal today is [specific outcome]. Respond as [tone/format preference]."

Conversation Threading

Instead of one mega-conversation, break complex projects into focused conversations — one per deliverable. Shorter conversations are faster, cheaper, and easier to navigate. Use the session summary method to carry context between them.

Iterative Refinement Within Context

Claude remembers everything said earlier in the same conversation. Use this: instead of re-explaining, say "Using the tone from the email you wrote in step 3, now write a LinkedIn post on the same topic." Claude will maintain consistency automatically.

Priority Stacking

When you need Claude to balance multiple constraints, list them in priority order explicitly. "In order of importance: (1) factual accuracy, (2) concise under 200 words, (3) professional tone." Claude weights the first items most heavily when trade-offs are required.

Context injection for APIs:

If you're using Claude via the API, you can pre-populate context programmatically via the system prompt. Build a context assembly function that composes the right project brief, user prefs, and current task automatically.

Suggested Prompts

Session Summary
"Summarise everything we've worked on in this conversation. Include: decisions made, open questions, key context I'll need, and clear next steps. Format it as a block I can paste at the start of a future chat."
Project Instructions Draft
"Help me write a Project Instructions document for my Claude project. My role is [role], the project is about [project], my key preferences are [preferences], and the main output I produce is [output]. Write instructions that I can paste directly into the project setup."
Custom Instructions Audit
"Here are my current Custom Instructions: [paste instructions]. Review them and suggest improvements — identify anything ambiguous, missing, or contradictory. Then give me a revised version ready to copy in."
Document Extraction
"Read the attached document and extract: (1) the three most important conclusions, (2) any data or statistics cited, (3) action items or recommendations. Present as a structured brief, not a summary of the whole document."
Cross-Document Analysis
"I'm uploading two documents: [Doc A] and [Doc B]. Compare them on these dimensions: [dimension 1], [dimension 2], [dimension 3]. Highlight where they agree, where they conflict, and what's in one but not the other."
Context Compression
"This conversation is getting long. Before we continue, compress everything discussed so far into a 200-word context brief. Preserve: decisions, open questions, key constraints, and the current task. I'll use this to start a fresh conversation."

Your Roadmap

1

Set Custom Instructions

Add your role, preferences, and tone defaults. Spend 15 minutes now to save hours long-term.

2

Create Your First Project

Pick your most active workstream. Pin the key reference files and write concise project instructions.

3

Practice the Session Summary

End your next three sessions by asking Claude to write a context summary. Build the habit before you need it.

4

Optimise Context Usage

Audit what you're pinning. Remove stale files. Learn when to split conversations vs. extend them.
