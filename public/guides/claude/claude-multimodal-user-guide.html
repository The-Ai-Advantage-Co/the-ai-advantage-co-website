What is Claude Multimodal?

Multimodal means Claude can work with more than just text. You can upload images, PDFs, spreadsheets, code files, and other file types — and Claude will read, interpret, and reason across all of them in a single conversation.

This transforms Claude from a writing assistant into an analytical collaborator. You can show it a chart and ask what it means, hand it a messy spreadsheet and ask for insights, or give it a codebase and ask for a review — all in plain English.

Image Analysis & Vision

Claude can see and interpret images — photographs, diagrams, charts, UI screenshots, whiteboards, scanned documents. It can describe what it sees, extract text, interpret data visualisations, and answer questions about image content.

📈 Chart & Graph Reading

Upload a chart from a report or presentation. Claude identifies trends, compares values, and explains what the data is saying in plain English.

📸 Screenshot Analysis

Share a UI screenshot or app interface. Claude can describe the layout, identify issues, or suggest improvements to the design or copy.

🔤 Text Extraction

Upload a photo of a whiteboard, handwritten notes, or a printed form. Claude reads and transcribes the text, even from less-than-perfect images.

🖼️ Diagram Interpretation

Share a process diagram, architecture diagram, or org chart. Claude describes the structure, identifies the flow, and answers questions about it.

How to get the best results from images

1

Be specific about what you want

"Describe this chart" is weak. "What is the trend in Q3 revenue, and what's the biggest anomaly?" is far more useful.

2

Provide context Claude can't see

If the chart is from an annual report, say so. If the screenshot is from a client's app, mention it. Context shapes interpretation.

3

Use follow-up questions

After the initial description, drill in: "Now compare that trend to what you'd expect from a healthy SaaS business." Claude can reason further from the same image.

Limitation:

Claude cannot reliably identify people in photos or read very small text in low-resolution images. For precise numerical extraction from complex charts, verify against the source data.

4

Data Files & Spreadsheets

Upload CSVs, Excel files, or JSON exports and Claude will analyse the data, surface insights, build summaries, and suggest or write formulas — all in plain English, no code required.

🔍 Exploratory Analysis

"What are the top 5 rows by revenue? What's the average deal size? Are there any anomalies in the data?"

📐 Formula Help

"Write an Excel formula to calculate the 90-day rolling average for the value in column D."

🗂️ Data Cleaning

"Identify rows with missing values. Suggest how to handle them — remove, fill, or flag."

📋 Reporting

"Summarise this sales data as a 3-paragraph executive briefing for a board report."

Large datasets:

For very large spreadsheets (thousands of rows), Claude works best when given a sample or a filtered subset. Export the relevant columns and rows first, then upload the trimmed file.

Python & SQL users:

You can paste a data sample and ask Claude to write a Python script or SQL query to process the full dataset. This extends Claude's reach to any data size.

Code & Technical Files

Claude can read, review, explain, debug, and rewrite code across almost any language. Upload source files directly or paste code snippets — Claude handles both.

Python · 312 lines · Uploaded
Code review: The main pipeline function lacks error handling for the API call at line 87. If the API returns a non-200 status, the script will crash silently.
Performance: The loop at lines 140–165 makes a database call on every iteration. This can be batched — pull all records first, then process in-memory.
Suggestion: Add logging at key stages (fetch, transform, load) so you can trace failures in production without re-running the full pipeline.

Advanced Techniques

Structured Extraction

Instead of open-ended summaries, ask Claude to extract specific data points into a structured format — table, JSON, or a numbered list. This makes outputs directly usable in other systems.

Example prompt:

"Read the attached invoices and extract each one as a JSON object with fields: vendor_name, invoice_number, date, amount, currency, due_date. Return an array of objects."

Iterative Document Refinement

Upload a draft document and refine it iteratively in the same conversation. Claude remembers the original throughout. First pass: structure. Second: tone. Third: specific sections. Each pass builds on the last without re-uploading.

Image-Anchored Writing

Upload a diagram, wireframe, or org chart and use it as the basis for written content. "Write the product description for the feature shown in this wireframe" produces grounded, accurate copy without you describing every detail.

Multi-File Analysis at Scale

Claude can handle multiple file uploads in one conversation. Upload 5–10 short documents and ask for a synthesis: "Read all these reports and identify the three themes that appear most consistently across them."

Power move:

Combine structured extraction with a template. "Extract the data from this report and fill in the attached Excel template accordingly." Claude maps data from unstructured sources into your predefined format.

Suggested Prompts

Document Brief
"Read this document and produce a one-page executive brief: key purpose, three most important findings or decisions, any risks or open questions, and clear next steps. Use bullet points throughout."
Chart Interpretation
"Describe what this chart is showing. What is the main trend? What's the most interesting or surprising data point? What business question does this help answer?"
Contract Risk Review
"Review this contract from the perspective of the party signing it. Flag: (1) any clauses that limit liability or indemnification unfairly, (2) auto-renewal or cancellation terms, (3) any missing standard clauses for this type of agreement."
Data Insight Extract
"Analyse this dataset and tell me: (1) the top 5 and bottom 5 by [metric], (2) any obvious outliers or anomalies, (3) one non-obvious insight I might miss on first glance. Don't give me everything — focus on what's actionable."
Code Review
"Review this code file. I want three categories of feedback: (1) bugs or errors that would cause failures, (2) performance issues or inefficiencies, (3) readability or maintainability improvements. Order by severity."
Structured Data Extraction
"Read the attached document and extract the following fields for each [entity]: [field 1], [field 2], [field 3]. Format the output as a markdown table with one row per [entity]. If a field is missing, mark it as N/A."

See It In Action

A multi-file analysis session — an image chart, a PDF, and a CSV uploaded together and analysed in one conversation.

Claude — New conversation
Attached Files
🖼️ Q3-Revenue-Chart.png
📄 Board-Report-Draft.pdf
📊 Sales-Data-Q3.csv
You: The chart is from slide 8 of the board deck. The PDF is the draft report this chart belongs to. The CSV is the raw data behind the chart. I need to know: does the chart accurately represent the data, does the commentary in Section 4 of the report match what the data shows, and what's the most important insight the board should take away?
Claude
Chart accuracy: The chart correctly represents Q3 data from the CSV, with one minor issue — the Y-axis starts at $400k rather than zero, which visually exaggerates the growth trend. The underlying growth is real (18% QoQ), but the presentation amplifies the visual impression.

Section 4 alignment: The report commentary says revenue "accelerated sharply in Q3." The data shows consistent growth, not acceleration — the rate is similar to Q2. I'd suggest softening the language to "continued strong growth."

Key board insight: Enterprise deals over $50k grew 34% while SMB deals declined 8%. This product/market mix shift is not mentioned in the current report and is the most strategically important finding in the data.
