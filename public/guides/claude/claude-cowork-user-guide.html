Claude Cowork Mode — User Guide

A practical guide to getting the most out of Cowork Mode — Claude's desktop tool for automating file and task management, without needing to write code.

Version 1.0 Updated: April 2026 Audience: All Users
01
What is Cowork Mode?
Your AI-powered desktop workspace

Cowork Mode is a feature of the Claude desktop application that gives you a persistent, AI-powered workspace directly on your computer. Unlike the standard chat interface, Cowork Mode connects Claude to your actual files, folders, and tools — so it can read, write, organise, and act on your behalf, not just advise.

It is designed for non-developers who want to automate real work — document creation, research, file organisation, reporting, and integration with tools like HubSpot, Google Calendar, and Stripe — without touching code or learning complex software.

📁
File Access
Read, write, and organise files directly in your OneDrive or local folders.
🔗
Live Integrations
Connected to HubSpot, Stripe, Gmail, Calendly, Figma, and more via MCP.
⚡
Skills & Plugins
Specialist capabilities like PPTX creation, PDF handling, and XLSX automation.
🎯
Persistent Workspace
Files saved to your workspace folder persist between sessions on your computer.
💡
Think of it this way
Cowork Mode is like having a capable team member sitting inside your desktop — one who can open your files, draft documents, pull data from your CRM, and build reports, all from a single conversation.

What it is not

Cowork Mode is not a fully autonomous agent that runs in the background without your input. It acts when you ask it to, confirms before irreversible actions, and keeps you in control of all final decisions. Sensitive actions (sending emails, publishing content, financial transactions) require your explicit approval before Claude proceeds.

Getting Started
Set up your workspace in under five minutes

Cowork Mode is built into the Claude desktop app. There is no separate installation required. Follow these steps to get your workspace ready.

1
Open the Claude desktop app
Launch Claude from your Applications folder (Mac) or Start menu (Windows). Make sure you are signed in with your Claude account. Cowork Mode is available on Pro and Team plans.
2
Select a workspace folder
In the Cowork Mode interface, click Select Folder and point Claude to your OneDrive, Documents folder, or any local directory. This becomes Claude's working directory — it can read and write files here. Your selection persists between sessions.
3
Connect your tools (optional)
Navigate to Settings → Connectors to link external tools: HubSpot CRM, Gmail, Google Calendar, Stripe, Calendly, Figma, Canva, and Zoom are all available. Each connector requires a one-time authorisation.
4
Install plugins (optional)
Plugins extend Claude with specialist skills. Browse the plugin marketplace in Settings or install a .plugin file directly. Installed skills appear automatically in your sessions.
5
Start a session and give Claude a task
You're ready. Open a new Cowork session and describe what you want done in plain language. Claude will ask clarifying questions if needed, then get to work.
ℹ️
Good to know
Files created in your workspace folder are yours and persist permanently on your computer. Temporary working files in the session cache are cleared between sessions — your final outputs are always safe.

Core Features
What Claude can do inside your workspace

Cowork Mode gives Claude access to a set of powerful capabilities that go well beyond standard chat. Here is what's available in every session.

File Tools

Claude can read any file in your workspace, write new files, and edit existing ones. It handles plain text, Markdown, HTML, and binary files (with the right skills installed). All changes are tracked and reversible — Claude tells you what it changed.

💡
Always saves to your folder
Final deliverables (documents, spreadsheets, presentations) are always saved to your workspace folder so you can access them directly. Temporary scratch work lives in the session cache and clears automatically.

Web Search & Research

Claude can search the web, fetch web pages, and read documentation — then incorporate findings into documents or reports without you switching between apps. It cites sources when it uses external content.

Code Execution

For tasks that need computation — data processing, file conversion, formula checks — Claude runs code in an isolated Linux sandbox. You don't write the code; Claude does, runs it, and gives you the result.

Artifact Creation

Claude can produce live HTML artifacts that render as interactive panels inside Cowork — dashboards, trackers, and forms that can call your connected tools and refresh data each time you open them.

📄
Documents
Word docs, PDFs, Markdown reports — created and formatted to spec.
📊
Spreadsheets
Excel files with formulas, formatting, charts, and structured data.
🖼️
Presentations
PowerPoint decks with layouts, branding, and speaker notes.
📈
Live Dashboards
Interactive HTML artifacts that pull from your connected tools.

Working with Files
Reading, writing, and organising your documents

Your workspace folder (typically your OneDrive or a local folder you selected) is Claude's operating environment. Claude can read everything inside it and write final outputs back to it.

File Operations Reference

Action What Claude does Example prompt
Read Opens and reads any file in your workspace, including binary files like DOCX and XLSX. "Summarise the proposal in /02 - Clients/Acme/proposal.docx"
Write Creates a new file in your workspace. Overwrites if the file exists (Claude warns you first). "Create a weekly report template and save it to /02 - Templates/"
Edit Makes precise changes to an existing file — replaces specific text without rewriting the whole file. "Update the pricing section in this SOW — change $4,000 to $5,500"
Organise Moves, renames, or restructures files and folders using shell commands in the sandbox. "Move all 2024 invoices into a new /Archive/2024/ folder"
Search Finds files by name pattern, content keywords, or modification date across your workspace. "Find all documents that mention 'onboarding' in the client folder"
⚠️
Permanent deletions
Claude will not permanently delete files on your behalf — this is a safety rule. If you need to delete files, Claude will tell you which ones to remove and you do it directly. Move-to-archive is always offered as an alternative.

Uploading files into a session

You can drag files directly into the Cowork chat window to attach them. Claude reads the contents immediately — useful for files outside your workspace folder. PDFs, images, CSVs, Word docs, and plain text are all supported.

Linking Claude to your design system

Store master templates (HTML, DOCX, PPTX) in a dedicated folder like 06 - Brand / Claude Design System /. In future sessions, tell Claude to use that template and it will pull from your saved version — keeping all outputs on-brand automatically.

Plugins & Skills
Extending Claude with specialist capabilities

Skills are specialist capability packs that Claude activates automatically when a task matches. Plugins are installable bundles that can include skills, MCP connectors, and custom instructions — all packaged as a single .plugin file.

Built-in skills (available now)

  • PPTX — Create, edit, and read PowerPoint presentations with full formatting control.
  • DOCX — Generate professional Word documents with styles, tables, headers, and TOC.
  • XLSX — Build Excel spreadsheets with formulas, conditional formatting, and charts.
  • PDF — Create PDFs, extract content, merge files, and fill forms.
  • Canvas Design — Generate visual designs and export as PNG or PDF.
  • Web Artifacts Builder — Build interactive HTML/React dashboards and tools.
  • Scheduled Tasks — Set tasks to run automatically on a recurring interval.
  • MCP Builder — Build your own MCP server to connect a new tool or API.
💡
Skills trigger automatically
You don't need to activate skills manually. When you ask Claude to "create a PowerPoint" it reads the PPTX skill guide first, then builds the file. The result is consistently better than asking without skills installed.

Installing a plugin

1
Get a .plugin file
Either download from the Claude plugin marketplace or receive one from a colleague or vendor.
2
Open Claude Settings → Plugins
Click "Install Plugin" and select the .plugin file. Claude validates and installs it.
3
Restart the session
Start a new Cowork session — the plugin's skills and connectors are available immediately.
ℹ️
Creating custom plugins
Ask Claude to use the Create Cowork Plugin skill to scaffold a new plugin from scratch. Useful for packaging your organisation's templates, connectors, and custom skills into a single shareable bundle.

Best Practices
How to work efficiently with Cowork Mode

Cowork Mode is most effective when you treat Claude as a capable operator who needs clear context — not as a search engine or a guesser. The more specific your instructions, the faster and better the output.

Do this

  • Give Claude the full context upfront. Tell it what you want, who it's for, and what format you need — in one message. Claude asks follow-up questions when needed, but clear briefs save time.
  • Reference files by path. Instead of "that proposal", say "the proposal in /02 - Clients/Acme/". Specific paths prevent Claude from guessing which file you mean.
  • Save master templates to your design system folder. Claude will pull from them automatically for consistency across all future documents.
  • Use Markdown files as your content source of truth. Store SOPs, guides, and frameworks as .md files — Claude reads and updates them efficiently.
  • Build incrementally. For complex workflows, start manual (ask Claude to do one step), verify the output, then ask it to do the next. Automate later once you've validated the pattern.
  • Confirm before irreversible actions. Claude will ask you before sending emails, submitting forms, or modifying records. Read the confirmation carefully before approving.

Avoid this

  • Vague briefs. "Do something with my files" gives Claude nothing to work with. Describe the specific task, format, and outcome you want.
  • Assuming Claude remembers previous sessions. Each session starts fresh. Reference the specific file, document, or context Claude needs — don't assume it knows from last time.
  • Jumping to automation before validating. Run any workflow manually at least twice before asking Claude to schedule it. Automating a broken process just breaks it faster.
💡
The 3-part brief formula
What I need + who/what it's for + format/output required.
Example: "Write a proposal summary (WHAT) for the Acme onboarding project (WHO) as a one-page Word document with our logo header (FORMAT)."

Troubleshooting
Common issues and how to fix them

Claude can't find my files

Make sure you've selected a workspace folder in Cowork Mode settings. Claude can only access files inside the folder you've connected. If your files are elsewhere, you can drag them into the chat window to attach them directly, or update your workspace folder selection.

My file tools have stopped working

This usually means the filesystem MCP has dropped its connection. Type /mcpreset in the chat — this triggers the MCP reset skill which diagnoses and re-establishes the connection automatically. If the issue persists, restart the Claude desktop app.

A connector shows as disconnected

Authorisation tokens expire periodically. Go to Settings → Connectors, find the affected connector, and click Reconnect. You'll be asked to re-authorise with that service. This typically takes under 30 seconds.

Claude is producing outputs in the wrong format

Be explicit about the output format in your prompt. Say "save this as a .docx file" or "export this as PDF". If you want Claude to use your brand template, say "use the template in /06 - Brand/Claude Design System/" — without a reference Claude will use its defaults.

The session seems to have lost context mid-task

Very long sessions can hit context limits. If this happens, start a new session and reference the specific files and tasks you need. Good practice is to save progress checkpoints to your workspace folder so you can resume efficiently from a fresh session.

Suggested Prompts
Copy and paste these to get started immediately

Not sure what to ask first? These prompts are ready to use. Copy one, paste it into your Cowork session, and Claude will handle the rest.

CRM & Pipeline
"Pull my HubSpot contacts updated this week, summarise any open deals by stage, and save it as a one-page pipeline report to my client folder."
Revenue & Reporting
"Check my Stripe account for the last 30 days — total revenue, top products by sales, and any failed payments — then build a summary dashboard I can open each Monday morning."
Client Documents
"Read the proposal in my Clients/Acme folder, update the pricing section to reflect a 15% increase, and save a revised version with today's date in the filename."
Meeting Prep
"Look at my Google Calendar for next week and create a one-page briefing document for each meeting — who it's with, what we last discussed in HubSpot, and three suggested talking points."
Weekly Review
"Run my weekly business review: summarise emails from this week, check any open HubSpot tasks, list Stripe transactions over $500, and compile everything into a structured markdown review file."
Study Guide
"Read my lecture notes in the attached PDF and create a structured study guide with key concepts, definitions, and five practice questions I can use to test myself."
Essay Writing
"Help me write a 2,000 word essay on [topic]. Start with a detailed outline for my approval, then draft each section one at a time. Use an academic tone with in-text citations."
Research Summary
"Search for three current academic perspectives on [topic] and produce a comparison table with the key argument, supporting evidence, and limitations of each view. Save it as a Word document."
Revision Planner
"Build me a four-week revision timetable for my upcoming exams. My subjects are [list them]. Spread the topics evenly, allow for rest days, and format it as a printable Excel spreadsheet."
PDF Simplification
"I've attached a 40-page academic paper. Summarise it in plain English — what the researchers did, what they found, and why it matters. Pull out five key quotes I can use in my assignment."

Your Roadmap
From your first prompt to a fully repeatable workflow

You don't need to set everything up perfectly before you start. Cowork Mode is designed for iteration — start with a single prompt and build from there.

1
Type your first prompt
Plain English. Describe what you want done and what format you need.
2
Claude clarifies
If anything is ambiguous, Claude asks one focused question before starting.
3
Claude reads & connects
It accesses your files, pulls from connected tools, and gathers what it needs.
4
Output delivered
File saved to your folder. Claude confirms and offers the next logical step.
5
You review & refine
Approve, redirect, or ask Claude to iterate. Each session builds on the last.
6
Automate it
Once the workflow is solid, schedule it to run automatically on a set interval.
📍
Where most people start
Pick one recurring task you do every week — a report, a review, a document you update — and run it manually with Claude twice. Once you've confirmed the output is right, use the Schedule skill to automate it. That's the whole playbook.
Suggested first prompt to try right now
"Look at my workspace folder and tell me what's in it. Then suggest three tasks you could help me with based on what you find."
This lets Claude get oriented in your setup before you ask it to do anything significant — the best possible first step.
