What is Claude?
An AI assistant built to be genuinely helpful, honest, and safe

Claude is an AI assistant made by Anthropic. You talk to it in plain English — or any language — and it responds with thoughtful, well-reasoned answers. It can write, analyse, summarise, research, code, brainstorm, and reason through complex problems. It works like a very capable colleague who is always available and never impatient.

What sets Claude apart is how it's built. Anthropic has trained Claude to be helpful and honest — it will tell you when it doesn't know something, push back on instructions that seem wrong, and decline requests that could cause harm. It's designed to work with you, not just for you.

✍️
Write & Edit
Drafts, emails, reports, blog posts, scripts — any written task, any tone.
🔍
Research & Analyse
Summarise documents, compare options, extract insights from data.
💻
Code & Build
Write, review, explain, and debug code across dozens of languages.
🧠
Think & Plan
Work through decisions, structure complex problems, stress-test ideas.
💡
Claude is not a search engine. It doesn't browse the web by default — it reasons from its training and any context you provide. For current events, use the web search feature (available in Claude.ai) or paste the information directly into your message.

Writing Effective Prompts
How to talk to Claude to get the best results

You don't need a special skill to use Claude — but a few habits make a noticeable difference in the quality of responses you get. The single biggest factor is specificity. The more Claude knows about what you need, the better it can deliver.

The Four Things That Matter Most

ElementWhy It MattersExample
Role / contextTells Claude who it's speaking to and what background applies"I'm a marketing manager at a B2B software company…"
The taskBe specific about what you want produced"…write a 3-paragraph cold outreach email…"
FormatTell Claude how to structure the output"…as bullet points, no longer than 200 words…"
ConstraintsWhat to include, avoid, or prioritise"…avoid jargon, keep the tone friendly but professional"

Weak vs. Strong Prompts

❌
Weak: "Write me an email about the project." — Claude doesn't know who it's for, what the project is, what tone to use, or how long it should be.
✅
Strong: "Write a short email (under 150 words) to a client explaining that their project will be delayed by two weeks due to a supplier issue. Tone: apologetic but confident. End with a specific next step."

Other Useful Habits

  • Iterate, don't start over. If the first response isn't right, reply with what to change — Claude uses the full conversation as context.
  • Paste in your content. Give Claude the document, data, or text it's working with directly in the chat.
  • Ask Claude to explain its reasoning. Adding "explain your thinking" surfaces assumptions and catches errors early.
  • Use follow-up questions. Claude works well in back-and-forth. Dig deeper, ask for alternatives, or request a different angle.

Projects & Organisation
Keep related work together with shared context and instructions

Projects let you group related conversations together and give Claude persistent instructions that apply to every conversation within that Project. Instead of re-explaining your role, team, or preferences in every new chat, you set it once in the Project and it applies automatically.

📋
Custom Instructions
Set Claude's persona, rules, and context once — applies to every chat in the Project.
📂
Shared Files
Upload documents to the Project and Claude can reference them in any conversation.
🗂️
Grouped History
All conversations in a Project stay grouped and easy to find later.
👥
Team Sharing
Share Projects with teammates on Team and Enterprise plans.
1
Click "Projects" in the sidebar and create a new Project
Give it a clear name — e.g. "Client Comms — Acme Co" or "Q3 Marketing Campaign".
2
Add Project Instructions
Write a system-level description: who you are, what this Project is for, Claude's role, and any rules to follow. This is applied to every chat automatically.
3
Upload reference files
Brand guidelines, product docs, templates, previous reports — anything Claude should know across all chats in this Project.
4
Start conversations inside the Project
Every new chat opened within this Project will have your instructions and files available automatically.
💡
Good Project Instructions make every chat better. Invest 10 minutes writing a strong set of instructions the first time — you'll save far more time across every subsequent conversation.

Files & Artifacts
Uploading content and what Claude creates for you

You can give Claude content to work with by uploading files directly into the chat. Claude can read and reason over the contents — no copy-pasting required. When Claude produces significant outputs, it often creates them as Artifacts — a separate preview pane alongside the conversation.

What You Can Upload

File TypeWhat Claude Can Do With It
PDF / Word docSummarise, extract key points, answer questions about the content, rewrite sections
Images (PNG, JPG)Describe, analyse, read text in images (OCR), identify objects, review diagrams and charts
CSV / spreadsheet dataAnalyse patterns, calculate values, explain trends, suggest next steps
Code filesReview, debug, explain, refactor, or extend existing code
Text / transcript filesMeeting notes, transcripts, logs, plain text content of any kind

Artifacts

When Claude creates something substantial — a document, a code snippet, an HTML page — it displays it as an Artifact in a side panel. Artifacts make it easy to view, copy, and iterate on Claude's output without cluttering the chat.

  • Documents — formatted text, reports, emails, templates
  • Code — runnable scripts with syntax highlighting
  • HTML / React — live-rendered previews you can interact with
  • SVG / Diagrams — visual outputs rendered in the side panel
ℹ️
Artifacts are not saved automatically. Copy or download what you need before closing the conversation, or save important outputs to a Project for easier access later.

Claude's Values & Limits
How Claude thinks, what it won't do, and why

Claude is not a neutral tool that will do anything asked of it. Anthropic has trained it with specific values — to be helpful, honest, and to avoid causing harm. Understanding these values helps you work with Claude more effectively and sets realistic expectations.

Claude Will Always

  • Tell you when it's uncertain. Claude says "I don't know" rather than making things up — though it can still make mistakes. Verify important claims independently.
  • Push back constructively. If a request seems misguided, Claude will say so — but it will still try to help with the underlying goal where possible.
  • Explain its reasoning on request. Ask Claude to show its thinking and it will. Useful for auditing important outputs.
  • Acknowledge it's an AI. Claude won't pretend to be human when sincerely asked.

Claude Will Not

  • Provide instructions for creating weapons, malware, or content designed to cause harm
  • Produce sexual content involving minors under any circumstances
  • Help with clearly illegal activities targeting other people
  • Fabricate citations, quotes, or sources (though it can still hallucinate — always check)

What to Do When Claude Declines

If Claude refuses a request, the framing may have triggered a concern — not necessarily that the underlying need is illegitimate. Try rephrasing with more context about your purpose. If the refusal still seems too cautious, use the thumbs-down button to give Anthropic feedback.

ℹ️
Claude can be wrong. It's a capable assistant, not an infallible expert. For medical, legal, financial, or safety-critical decisions, always verify Claude's output with a qualified professional.

Context Window

Claude has a context window — the amount of text it can hold in memory at once. Claude currently processes up to 200,000 tokens (roughly 150,000 words) per conversation. For very long conversations, earlier messages may eventually fall outside this window, which can affect response continuity.

Suggested Prompts
Ready-to-use prompts to get you started immediately

Copy any of these directly into Claude to see what it can do. They're designed as templates — replace the bracketed parts with your own details.

Learning Something New
"Explain [topic] to me as if I have no background in it. Use simple language, give a concrete real-world example, and tell me the three most important things I should understand first."
Making a Decision
"I'm trying to decide between [option A] and [option B]. Here's my situation: [brief context]. Help me think through the key trade-offs. Don't give me a final answer — help me reason it through myself."
Planning & Organisation
"I need to [achieve goal] by [date]. I have [resources/constraints]. Help me create a practical, step-by-step plan that is realistic for someone with limited time. Flag anything I might have missed."
Writing Feedback
"Please review the following text and give me honest feedback. Focus on: (1) clarity, (2) tone, (3) structure. Tell me what's working, what isn't, and give specific suggestions to improve it. [paste your text below]"
Summarise Anything
"Summarise the following in plain English. Give me: (1) a one-sentence summary, (2) three key takeaways, and (3) one thing I should do or think about as a result. [paste content below]"
Draft a Professional Email
"Write a professional email from me to [recipient/role] about [subject]. Tone: [formal/friendly/assertive]. Key points to cover: [list them]. Keep it under [word count] words. End with a clear call to action."
Meeting Prep
"I have a meeting with [who] about [topic] on [date]. My goal is [outcome]. Help me prepare: suggest 5 questions I should ask, 3 things I should know going in, and a one-paragraph summary I could send beforehand."
Analyse a Document
"I'm going to paste a [report/proposal/contract] below. Read it carefully and tell me: (1) the main argument or purpose, (2) any gaps or weak points, (3) three questions I should be asking about it. [paste document below]"
Build a Project Instruction Set
"Help me write a Claude Project instruction set for this use case: I am a [role] at a [company type]. I'll be using this Project to [task description]. Ask me three clarifying questions first, then draft the instructions."
Stress-Test an Idea
"Here is a plan I'm considering: [describe it]. Play devil's advocate. What are the three strongest arguments against it? What assumptions am I making that might be wrong? What would need to be true for this to fail?"

Your Roadmap
Five steps to get up and running with confidence

You don't need to master everything at once. Follow these five steps in order and you'll be using Claude effectively within a week.

1
Create your account and have three real conversations
Don't use test prompts — use something you actually need today. Draft an email, summarise a document, plan your week. Real use cases reveal what Claude can do for you faster than any tutorial.
2
Practice writing specific, structured prompts
Take a vague request and rewrite it using the four elements: role, task, format, constraints. Compare the quality of the two responses. Do this three times and the habit will stick.
3
Set up your first Project
Pick one recurring work area — client comms, research, content creation — and create a Project for it. Write the instructions carefully. Use it for a week and notice how much less re-explaining you're doing.
4
Try uploading a file
Upload a real document — a PDF report, a spreadsheet, a meeting transcript — and ask Claude meaningful questions about it. This is one of the highest-value use cases and most people discover it too late.
5
Identify your top three recurring tasks and build prompts for them
Think about what you do repeatedly — weekly reports, client updates, research summaries. Write a reusable prompt template for each one and save them somewhere accessible. This is the point where Claude stops being occasional and becomes essential.
🚀
The fastest way to get value from Claude is to use it on real work, not test prompts. Bring it into something you're already doing today and let the results speak for themselves.
