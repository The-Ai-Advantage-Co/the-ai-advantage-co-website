What is Memory & Custom Instructions?

Two features that eliminate repetitive context-setting

By default, ChatGPT starts every conversation completely fresh — no memory of who you are, how you prefer to work, or any previous context you've shared. Two features solve this: Custom Instructions and Memory.

📋

Custom Instructions

Permanent rules you write that apply to every conversation. Tell ChatGPT your role, your preferences, how you want it to communicate — once, and it sticks.

🧠

Memory

Facts ChatGPT learns automatically as you chat — your name, job, projects, preferences. It stores these and recalls them in future sessions.

📁

Project Instructions

Per-project context that applies only within a specific Project. Ideal for maintaining different personas or contexts for distinct workstreams.

⏱️

Temporary Mode

A session-only mode where nothing is remembered or stored. Useful for sensitive tasks or starting completely fresh without affecting your memory bank.

💡
The Core Problem They Solve

Without these features, every session requires re-explaining your role, audience, tone preferences, and project context. With them, ChatGPT already knows — letting you start every conversation at the useful part.

Without vs With Context Features

❌ Without Memory / CI
✗ Re-explain your role every session
✗ Re-state tone and format preferences
✗ Repeat project context each time
✗ Generic responses not tailored to you
✗ 10–15 minutes wasted per session
✅ With Memory / CI Active
✓ ChatGPT knows your role and org
✓ Consistent tone and format every time
✓ Project context pre-loaded
✓ Responses personalised by default
✓ Start useful immediately

How ChatGPT Memory Works

Automatic recall — what gets stored and when it's used

Memory works automatically in the background. As you chat, ChatGPT identifies facts worth saving — about you, your work, your preferences — and stores them. On future conversations, it draws on those stored facts to give more relevant, personalised responses.

What Gets Remembered

👤
Identity & Role
User is a senior product manager at a B2B SaaS company. Team of 8 direct reports.
×
✍️
Communication Preferences
Prefers concise, direct responses. No bullet points for analysis — prose paragraphs only.
×
📌
Active Projects
Working on a Q3 product roadmap. Target launch: September. Stakeholder: VP of Engineering.
×
⚙️
Tool Preferences
Uses Notion for docs, Linear for project tracking, Slack for team comms.
×
💡
How Memory Is Triggered

ChatGPT stores memories when you share personal context ("I'm a nurse at a busy A&E"), express preferences ("I always want bullet points"), or mention ongoing work. You don't need to explicitly ask it to remember.

You Can Also Tell It Explicitly

How to manually seed a memory
Simply say: "Remember that I prefer executive summaries over detailed reports" or "Please note that I work in the healthcare sector." ChatGPT will confirm it has stored the fact and you'll see it appear in your memory list.
Where to find stored memories
Go to Settings → Personalisation → Memory → Manage Memories. You'll see every stored fact, when it was created, and have the option to delete individual items or clear all memories at once.
When memories are used
ChatGPT references stored memories at the start of each new conversation. It doesn't surface them explicitly unless relevant — they work silently in the background to shape responses.
ℹ️
Memory Availability

Memory is available to ChatGPT Plus, Team, Enterprise, and Edu users. Free users have limited access. Memory is disabled in Temporary Chat mode and (by default) in GPTs unless the GPT creator has enabled it.

03

Setting Up Custom Instructions

Write once, apply to every conversation

Custom Instructions are two text fields you fill in once in Settings. Unlike Memory — which ChatGPT controls — Custom Instructions are entirely yours to write and update. They persist across every conversation and take effect immediately.

The Two Fields

⚙️ Custom Instructions
Settings → Personalisation
📘 What would you like ChatGPT to know about you?
I'm a senior product manager at a B2B SaaS company focused on HR tech. I lead a team of 8 and report to the CPO. I work across product strategy, stakeholder management, and roadmap planning. My audience for most writing tasks is either technical leads or C-suite executives.
Who you are, your role, organisation, and audience. Give ChatGPT the context it needs to calibrate expertise level and relevance.
🟣 How would you like ChatGPT to respond?
Be direct and concise. Lead with the most important point — no preamble. Use bullet points for lists, prose for analysis. Avoid hedging language. When I ask for options, give me your recommended choice first with clear reasoning. Max 300 words unless I ask for more.
Tone, format, length, communication style. Tell ChatGPT exactly how you want it to behave by default.

How to Access Custom Instructions

1

Open Settings

Click your profile picture in the top-right corner of ChatGPT → select Settings from the dropdown menu.

2

Go to Personalisation

Select the Personalisation tab in the left sidebar of the Settings panel.

3

Click Custom Instructions

You'll see both text fields. Write your content — up to 1,500 characters per field.

4

Save & Activate

Click Save. Your instructions take effect on all new conversations immediately. Existing conversations are unaffected.

💡
What Makes Great Custom Instructions

Field 1 (About you): Role + organisation type + primary audience. Field 2 (How to respond): Specific tone words, format rules, length limits, and what to avoid. The more concrete the instruction, the more consistently ChatGPT applies it.

Field 2 Examples by Role

RoleExample "How to respond" instruction
Marketing ManagerWrite in an engaging, conversational tone. Lead with the hook. Use active voice. Avoid jargon and corporate speak. Keep first drafts under 200 words unless asked for more.
Software EngineerBe precise and technical. Skip explanations of basic concepts. Show code in the relevant language with comments. When there are multiple approaches, list trade-offs briefly.
ConsultantLead with the insight, support with evidence. Use a structured format (situation → problem → recommendation). Assume a senior stakeholder audience. Be brief — executives skim.
EducatorExplain concepts as if to a bright 16-year-old with no prior knowledge. Use analogies. Check understanding by ending with a key question. Avoid jargon without explanation.
04

Managing Your Memory

View, edit, and curate what ChatGPT knows about you

Memory is not set-and-forget. Over time, ChatGPT may store outdated facts, duplicate information, or things you'd prefer it didn't retain. Regular curation keeps your memory bank accurate and useful.

Managing Individual Memories

1

View All Memories

Settings → Personalisation → Memory → Manage Memories. You'll see a full list of stored facts with timestamps.

2

Delete Individual Facts

Click the × icon next to any memory to remove it permanently. Useful for removing outdated project info, old job titles, or incorrect facts.

3

Update via Conversation

Tell ChatGPT "Update your memory — I've moved to a new role as Head of Design." It will store the new fact. You may still need to manually delete the old one.

4

Clear All Memories

Settings → Personalisation → Memory → Clear Memory. This wipes your entire memory bank — useful if your context has changed significantly or you want a fresh start.

⚠️
Clearing Memory Is Permanent

There is no undo for clearing all memories. ChatGPT will start learning from scratch. Consider reviewing and deleting specific outdated memories rather than clearing everything.

Memory Hygiene Checklist

Monthly Review

Check stored memories for outdated job titles, finished projects, or preferences that have changed. Delete anything no longer accurate.

After Role Changes

Update ChatGPT on any significant life or career changes — new role, new employer, new audience. Old context can cause consistently misaligned responses.

After Project Completion

Delete project-specific memories once a project is done. Stale project context can bleed into unrelated conversations.

Watch for Duplicates

ChatGPT sometimes stores similar facts twice. Duplicate memories don't cause harm but clutter your memory list — delete the older version.

💡
Ask What It Remembers

At any time, type "What do you remember about me?" ChatGPT will summarise its current memory of you — a quick way to audit without going into Settings.

Memory in Projects

Context that stays within a specific workstream

Projects are ChatGPT's way of keeping work organised. Each Project has its own persistent instruction set, file uploads, and conversation history — separate from your global Custom Instructions and Memory. Think of Projects as dedicated workspaces for distinct areas of your work.

Global vs Project-Level Context

FeatureGlobal (Custom Instructions / Memory)Project Level
ScopeAll conversations everywhereOnly inside that Project
Who sets itYou (CI) or ChatGPT learns it (Memory)You write Project instructions manually
Best forPermanent preferences, role, communication styleProject-specific context, brief, audience
Examples"Always be concise", "I'm a product manager""This project is a rebrand for client X. Tone: aspirational. Audience: CMOs."
File accessNot persistent across sessionsUploaded files stay in the Project
💡
Project Instructions Stack With CI

When you're inside a Project, both the Project-level instructions AND your global Custom Instructions are active. Project instructions take precedence when there's a conflict. Use this to override your global defaults for a specific context.

Setting Up Project Instructions

1

Create or Open a Project

Click Projects in the left sidebar → New Project, or open an existing one.

2

Open Project Settings

Click the gear icon or the Project name at the top → Edit Project Instructions.

3

Write Project-Specific Context

Include: project name, goal, client or stakeholder, audience, tone, and any standing rules specific to this workstream.

4

Upload Reference Files

Add briefs, style guides, previous outputs, or research documents. ChatGPT will reference these throughout the Project.

ℹ️
Recommended Project Architecture

Use one Project per major client, one per long-running internal initiative, and one as a "Personal" catch-all. Avoid creating a new Project for every task — Projects work best for workstreams lasting weeks or months.

Privacy & Memory Control

What's stored, what's shared, and how to stay in control

Memory stores information in your account and uses it to personalise responses. Understanding what's stored and how to control it lets you use Memory confidently without privacy concerns.

What OpenAI Does With Memories

Stored in Your Account

Memories are tied to your OpenAI account and used only to personalise your own ChatGPT responses. They are not shared with other users.

May Inform Model Training

By default, conversations (including memory) may be used to improve OpenAI models. You can opt out in Settings → Data Controls → Improve the Model for Everyone.

Enterprise Accounts

ChatGPT Enterprise and Team accounts have enhanced privacy guarantees — conversations are not used for training by default, and admins control memory policies.

Temporary Chat

Start a Temporary Chat (top of sidebar) and nothing from that session is stored to memory or used for training. Ideal for sensitive or confidential tasks.

⚠️
Never Store Sensitive Information in Memory

Avoid telling ChatGPT passwords, financial account numbers, client PII, or confidential contracts in a way you'd expect it to memorise. For sensitive tasks, use Temporary Chat mode.

Privacy Control Options

ControlWhere to Find ItWhat It Does
Turn off Memory entirelySettings → Personalisation → Memory toggleChatGPT stops storing new memories. Existing memories remain until deleted.
Use Temporary ChatTop of sidebar → Temporary Chat iconSession is not saved, nothing added to memory, not used for training.
Delete specific memoriesSettings → Personalisation → Manage Memories → ×Removes that specific fact from your memory bank permanently.
Clear all memoriesSettings → Personalisation → Memory → Clear MemoryWipes entire memory bank. Cannot be undone.
Opt out of model trainingSettings → Data Controls → Improve the Model for EveryoneYour conversations are excluded from OpenAI training data.
💡
Best of Both Worlds

Keep Memory on for everyday tasks and productivity. Switch to Temporary Chat for anything involving client data, confidential strategy, or personal financial matters. You get personalisation when useful and privacy when needed.

Advanced Techniques

Power user strategies for persistent context

Once Custom Instructions and Memory are set up, these advanced techniques help you extract maximum value — building a richer, more tailored ChatGPT experience over time.

Deliberate Memory Seeding

Don't wait for ChatGPT to discover your preferences. Proactively tell it what you want remembered in your first few conversations. Use clear, direct statements:

🎯
Seed with intent
"Please remember: I always want responses under 250 words unless I specifically ask for more. No exceptions."
🎨
Seed tone preferences
"Note for future reference: I write in a witty, irreverent style for my newsletter. When helping with newsletter content, match that voice."
🔧
Seed tool preferences
"Remember: I use Notion for docs and Linear for tasks. When suggesting workflow steps, assume these tools."
💡
CI as a Style Guide

Use the "How to respond" field as a living style guide. Include your brand voice attributes, forbidden phrases, and preferred terminology. For teams on Enterprise, the admin can set org-wide Custom Instructions so all members get consistent outputs.

Persona Switching With Projects

Use different Projects to operate in genuinely different modes — even if you're the same person:

Professional Project

Formal tone, technical depth, report format. Overrides your global "be concise" instruction with "provide full analysis".

Creative Project

Experimental tone, no format constraints, permission to be unconventional. Completely different voice from your day job.

Client Project

Client's brand voice, client's audience, client's terminology. Keeps client context separate from your internal work.

Learning Project

Explain at depth, show examples, ask follow-up questions. Mode-shifts ChatGPT into a patient teacher for skill-building.

Iterative CI Refinement

1

Start Simple

Write a basic CI covering role + 2–3 format preferences. Don't try to anticipate everything.

2

Notice What's Missing

When ChatGPT misses your intent, ask yourself: "Could Custom Instructions have prevented this?" If yes, add that rule.

3

Update Monthly

Your role, priorities, and preferences evolve. Review and revise your CI regularly — treat it like your AI configuration file.

4

Test After Changes

After updating CI, run a test prompt on a typical task. Confirm the changes are having the intended effect before relying on them.

Common Mistakes & Fixes

What goes wrong and how to address it

❌ Custom Instructions are too vague to make a difference
Fix: Replace general adjectives with specific rules. Instead of "be professional", write: "Use formal language. No contractions. Lead with conclusions. Reference data where possible." Specificity is everything.
❌ ChatGPT isn't using my Custom Instructions
Fix: CI only applies to new conversations — not ones that were already open. Start a fresh conversation. Also check that CI is enabled (the toggle in Settings → Personalisation should be on). In Temporary Chat mode, CI is not applied.
❌ Memory stored something incorrect or private
Fix: Go to Settings → Personalisation → Manage Memories and delete the specific item. For future sessions, use Temporary Chat when discussing sensitive matters you don't want retained.
❌ ChatGPT applies the wrong tone for a specific task despite CI
Fix: Override CI inline for that prompt: "For this one task, ignore your usual tone instructions and write in a casual, friendly voice." ChatGPT will follow the in-conversation instruction for that response without changing your global CI.
❌ Memory has too many outdated facts and responses feel off
Fix: Do a full memory review — Settings → Manage Memories. Delete anything outdated, then explicitly seed fresh facts: "Remember that I'm now [new role] at [new company], working on [current project]."
❌ Project instructions aren't being followed consistently
Fix: Make Project instructions specific and actionable, not aspirational. Add concrete rules ("Always use British English", "Start every response with the key takeaway") rather than vague goals ("Be helpful and relevant").

Suggested Prompts

Ready-to-use prompts for memory and context management

Audit Current Memory
What do you currently remember about me? List every stored fact, organised by category (role, preferences, projects, tools). Flag anything that may be outdated.
Seed a Memory Deliberately
Please remember the following permanently: I am [your role] at [your organisation]. My primary audience for most tasks is [audience]. I always prefer [key preference 1] and [key preference 2]. Confirm what you've stored.
Update After Role Change
Update your memory about me: I've moved from [old role] to [new role] at [organisation]. My focus is now [new priorities]. Remove any stored context about [old project/context] as it's no longer relevant.
Draft Custom Instructions Field 1
Help me write the "What to know about me" field for ChatGPT Custom Instructions. I am [brief description of role, org, audience]. Ask me any clarifying questions you need, then draft a 200-word summary optimised for consistent, personalised responses.
Draft Custom Instructions Field 2
Help me write the "How to respond" field for Custom Instructions. My key preferences: [list 3–5 specific preferences — length, tone, format, what to avoid]. Draft a set of clear, actionable rules I can paste into Settings. Be specific, not aspirational.
Write Project Instructions
Help me write Project instructions for a ChatGPT Project. Project name: [name]. Goal: [goal]. Client/stakeholder: [who]. Audience: [who they communicate with]. Tone: [description]. Standing rules: [any specific constraints]. Draft a 150-word instruction set.
