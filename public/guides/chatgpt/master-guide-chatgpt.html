What is ChatGPT?
OpenAI's consumer and team chat surface

ChatGPT is OpenAI's chat surface, built on the GPT-5.5 family (as of 2026). It's available as a consumer product (Free, Plus, Pro) and as organisational plans (Team, Enterprise). Plus and above unlock the full feature surface — Memory, Custom GPTs, Canvas, Agent, Code Interpreter, image generation, voice.

  • Free — limited model access, no Memory
  • Plus ($20/mo) — GPT-5.5 family, Memory, Custom GPTs
  • Pro ($200/mo) — priority access, longer context, Pro features
  • Team ($25-$30/user/mo) — small org admin
  • Enterprise — SSO, audit logs, compliance, data residency

ChatGPT is the consumer/team chat surface for OpenAI's GPT-5.5 family. It ships as Free, Plus ($20/mo individual), Pro ($200/mo individual), Team ($25-$30/user/mo small org), and Enterprise (custom pricing for larger orgs). Plus and above unlock the full feature surface — Memory, Custom GPTs, Canvas, Agent, Code Interpreter, image generation, voice.

What differentiates ChatGPT from the other major foundation tools: the Custom GPT ecosystem (lightweight, fast to build), Canvas (the side-by-side editing mode for long-form work), Agent (autonomous task execution with browser and terminal), and a polished consumer experience that's hard for enterprise tools to match.

Where ChatGPT is the strongest choice

  • Open-canvas reasoning where the conversation IS the workspace (Canvas)
  • Code Interpreter / Advanced Data Analysis with file uploads
  • Custom GPTs — faster to build than competitors' equivalents
  • Agent (Operator) — autonomous task execution across the web
  • Voice mode — most polished consumer voice experience

Memory and Custom Instructions
The context layers

Two complementary layers shape ChatGPT's behaviour. Custom Instructions are static — you set them once. Memory is dynamic — ChatGPT learns from conversations. With 2026's Memory Sources, you can scope which past conversations Memory draws from.

Custom GPTs and Actions
Tailored assistants with API access

Custom GPTs let you build a tailored ChatGPT — with a specific personality, knowledge files, and conversation patterns. Actions let your GPT call external APIs. Together they're the lightest-weight way to deploy a domain-specific assistant.

🤖 CUSTOM GPTS VS COPILOT STUDIO
Custom GPTs are faster to build (10 minutes); Copilot Studio agents have deeper integration with M365 data. For a quick external-facing assistant, Custom GPTs. For tenant-grounded internal work, Copilot Studio.

Foundation — 101 + Prompt Engineering + Memory + Instructions
The everyday context stack for ChatGPT users

ChatGPT's foundation stack is wider than the other AI tools because of the context layers: the conversation, persistent Memory, and always-on Custom Instructions. Getting all four working together is what separates power users from casual users.

ChatGPT 101 — Getting Started

Model lineup (GPT-5.5 family), plans (Free / Plus / Pro / Team / Enterprise), the major surfaces, first prompts.

  • Model lineup: GPT-5.5 Instant (free default), GPT-5.5, GPT-5.5 Pro (reasoning)
  • Plans: Free / Plus ($20) / Pro ($200) / Team ($25-30) / Enterprise (custom)
  • Surfaces: Chat, Canvas, Custom GPTs, Agent, voice, image gen
  • Memory and Custom Instructions as always-on context
  • First prompts that work — specific brief, clear format, audience-aware

ChatGPT Prompt Engineering

The patterns that produce dramatically better ChatGPT outputs. Context-rich briefs, structured outputs, iteration loops.

  • Four-element brief: context, task, format, audience
  • Examples in the prompt — show, don't tell
  • Iteration loops — first draft → 'tighten the opening' → 'add a counterexample'
  • Reasoning mode (GPT-5.5 Pro) vs Quick (GPT-5.5) — match model to task
  • Anti-AI-slop discipline — cut hype words, vary rhythm

ChatGPT Memory Feature

Persistent memory across conversations. Memory Sources (2026) scope which past conversations Memory pulls from.

  • Auto-saved memory of your preferences, projects, recurring context
  • Memory Sources — selectable scopes for cross-conversation context
  • Configure in Settings → Personalization → Memory
  • Two-layer model: Custom Instructions (static rules) + Memory (dynamic learning)
  • Privacy — visible to you, not the people you message; deletable

ChatGPT Custom Instructions

The always-on context — set once in settings, applies to every conversation.

  • Box 1: 'what should ChatGPT know about you' — role, audience, constraints
  • Box 2: 'how should ChatGPT respond' — tone, format, length
  • 5-7 lines covers most contexts; quarterly review for staleness
  • Privacy: visible only to ChatGPT, not the recipients of your output
  • Don't include passwords, API keys, or sensitive credentials

Working Modes — Canvas + GPTs + Agent + Reasoning
The four power surfaces beyond standard chat

ChatGPT's distinctive surfaces in 2026 are Canvas (long-form editing), Custom GPTs (tailored assistants), Agent / Operator (autonomous tasks), and the reasoning models (GPT-5.5 Pro / o-series). Each is the right tool for a specific kind of work.

🎨 CANVAS IS THE 2026 DEFAULT
For any non-trivial writing, editing, or code work, Canvas is now the recommended surface. The right-click targeted editing pattern is meaningfully better than chat-then-paste. Open Canvas first.

ChatGPT Canvas

Side-by-side editing mode. The recommended surface for any non-trivial writing or code work in 2026. Right-click targeted edits are the underrated power feature.

  • Conversation left, live editable document right
  • Right-click selected text → ask for targeted change
  • Section-level shortcuts: shorten, lengthen, polish, rewrite for audience
  • Code in Canvas — strong for self-contained scripts and code review
  • Open Canvas first for long-form writing; chat-then-paste is the old workflow

ChatGPT GPTs — Finding, Using, Building

Custom GPTs: tailored assistants with system prompt, knowledge files, and Actions. Build in 10 minutes; deploy across team.

  • GPT Store for discovering existing GPTs across domains
  • Build your own: instructions + knowledge files + Actions + conversation starters
  • Knowledge files — up to 20 files per GPT (PDFs, docs, structured data)
  • Actions — call external APIs via OpenAPI 3.1 schemas
  • Team workspace — share GPTs with your org

ChatGPT Operator Mode and System Prompts

Operator (now branded as Agent in consumer ChatGPT) — autonomous task execution with virtual browser, terminal, and OpenAI API access.

  • Renamed from Operator to Agent in 2026 for consumer surface
  • Virtual machine with browser, terminal, OpenAI APIs
  • Multi-step tasks: research, form-filling, data extraction, workflow execution
  • Confirmation gates for destructive or expensive actions
  • Best for tasks where the alternative is human work, not chat responses

ChatGPT Advanced Reasoning

GPT-5.5 Pro and the o-series — specialised reasoning models for hard analysis, multi-step logic, code reasoning.

  • When to use: trade-off evaluation, complex code, multi-step reasoning
  • Latency: 20-60 seconds vs sub-second for standard models
  • Cost: meaningfully higher per token
  • Don't default to reasoning — match to task hardness
  • Hybrid pattern: standard model executes, reasoning model advises on hard sub-problems

Multimodal — Voice + Vision + Files + Image Gen + Video
ChatGPT beyond text

ChatGPT's multimodal surface is the most polished consumer multimodal AI in 2026. Voice mode for real-time conversation, vision for image understanding, file uploads for document work, native image generation, and video understanding.

ChatGPT Voice Mode

Real-time voice conversation. Most polished consumer voice experience in 2026. Sub-500ms latency, natural turn-taking, handles interruption.

  • Available on chatgpt.com, iOS, Android, Windows app
  • Multiple voices — different genders, accents, styles
  • Best uses: hands-free brainstorming, on-the-go briefings, language practice
  • Privacy considerations — captured and processed; not for confidential info in public
  • Length: voice favours conversational rhythm, not long technical content

ChatGPT Video Understanding and Analysis

Upload video clips (short to medium); ChatGPT analyses content, extracts moments, summarises, identifies objects/scenes.

  • Short clips up to ~30 min on Pro/Enterprise tiers
  • Use cases: meeting recordings, training videos, product demos, surveillance review
  • Specify timestamps for follow-up — 'at 3:42 the speaker mentions...'
  • Combined with transcript for highest-fidelity analysis
  • Privacy and consent — recording-with-AI rules apply

ChatGPT Image Generation

DALL-E lineage plus newer 2026 image models. Better text-in-image rendering (the 2026 unlock), photorealistic quality up, brand consistency tooling.

  • Four-element image prompt: subject, style, composition, constraints
  • Style vocabulary: photorealistic, illustration, 3D, watercolor, editorial, etc.
  • Brand consistency via reusable visual brief; encode in a Custom GPT
  • Iteration: 'same image but with [change]'
  • Limits: photo-real product shots glitch; named real people restricted

Use Cases — Where Teams Get Value
The use-case guides for specific work patterns

Beyond the foundation and working modes, the use-case guides cover specific work patterns where ChatGPT consistently produces strong results. Most teams adopt 2-3 of these as their core ChatGPT workflows.

ChatGPT for Business Writing

Drafting, editing, tone matching for everyday business writing — emails, briefs, reports, internal comms.

  • Four-element brief structure
  • Editing existing text often beats drafting from scratch
  • Tone matching via 3 paste-in samples
  • Canvas as default surface for anything over 200 words
  • Anti-AI-slop checklist before publishing

ChatGPT for Content and Social Media

Generating, repurposing, scheduling content at scale. Long-form to multi-platform shorts.

  • Repurposing pattern: one piece → tweet thread + LinkedIn + Instagram + email
  • Hook generation — generate 10, pick 2, A/B test
  • Voice matching via 5-10 sample posts; encode in Custom GPT
  • Content calendar building — themes + cadence → 4-week schedule
  • Quality vs quantity: 80% AI draft + 20% human judgement

ChatGPT for Data Analysis

Code Interpreter / Advanced Data Analysis — upload CSV/Excel, ask questions in plain English, get answers plus charts.

  • Upload CSV/Excel/JSON/Parquet; ChatGPT writes and runs Python
  • Question patterns: summarise, aggregate, trend, compare, outlier, forecast
  • Chart specification: type, axes, annotations, style
  • Statistical work: descriptive, correlation, regression, time series, hypothesis tests
  • Iteration: 'now break this down by [dimension]'

ChatGPT for Meeting Prep and Follow-Up

Pre-meeting briefs, in-meeting capture, post-meeting actions. With Memory + Projects, context carries across recurring meetings.

  • Pre-meeting brief: attendees, agenda, history, suggested questions
  • In-meeting: your own notes; AI transcription only with consent
  • Post-meeting recap: decisions, actions with owners, open questions
  • Follow-up email drafted from notes in seconds
  • Recurring meetings → Memory scope per person/project

ChatGPT for Research and Summarisation

Web search + Atlas Browser + Agent for research workflows. Citations, structured outputs, multi-source synthesis.

  • ChatGPT search (web tool) for fast grounded answers with citations
  • Atlas Browser / Agent for deeper multi-step research
  • Document upload for summarisation and extraction
  • Citation discipline — verify quotes and numbers
  • Combine web + your knowledge files for grounded synthesis

ChatGPT for Customer-Facing Use

Discipline for customer-facing comms. Drafting, tone, two-pass review, governance.

  • Two-pass pattern: AI drafts, human reviews — never auto-send
  • Templates and snippets via Custom GPTs for recurring patterns
  • Information discipline — what data goes in matters
  • Tone calibration via paste-in samples of your best customer comms
  • Compliance: approval workflow, audit log, disclosure where required

Platform & Developer Layer — Actions + API + Plans
Custom GPTs at depth, API for engineers, plan selection

The developer/platform layer extends ChatGPT from a chat product to a building block. Actions let Custom GPTs reach external APIs. The OpenAI API powers embedded use cases. Team and Enterprise plans add the admin/compliance layer organisations need.

ChatGPT Actions

Connect Custom GPTs to external APIs via OpenAPI 3.1 schemas. The 2026 Agent integration adds autonomous multi-step capability.

  • OpenAPI 3.1 schema defines endpoints, params, response
  • Auth options: None / API Key / OAuth / Custom
  • OAuth for user-scoped APIs (Gmail, Slack, GitHub)
  • 10 actions per Custom GPT maximum
  • 2026: Actions invokable by Agent for multi-step workflows

ChatGPT API Basics for Non-Developers

Using the OpenAI API without writing production code. No-code platforms, pricing, common patterns.

  • No-code platforms: Zapier, Make, n8n, Power Automate
  • Pricing: GPT-5.5 Instant ~$0.50/$2 per M tokens; GPT-5.5 ~$3/$15; Pro ~$15/$75
  • Set usage caps to prevent surprise bills
  • Estimate before scaling — run 100 first, validate, then expand
  • Advisor pattern (GPT-5.5 executes, GPT-5.5 Pro advises) for cost control

ChatGPT Team and Enterprise Plan Guide

Selecting between Team and Enterprise plans. Admin features, compliance, SSO, pricing thresholds.

  • Team: 2-200 users, $25-30/user/mo, basic admin, no SSO enforcement
  • Enterprise: 150+ seats, SSO, audit logs, BAA, data residency, custom pricing
  • Decision shortcut: SSO required → Enterprise; otherwise Team
  • Pilot first — 4 weeks, 20-50 users, capture wins
  • Renewal evidence: active users + time-saved cases per function

Common Mistakes & Fixes
What goes wrong — and how to avoid it

Most AI workflows that 'don't work' fall into one of these patterns. The fix is almost always sharper context and stricter review, not switching models or tools.

  • Treating ChatGPT Master Guide as a finished answer rather than a draft to review
  • Vague prompts that don't specify audience, format, or what you want changed
  • Forgetting to give it context — the file, the brief, the constraints
  • Skipping the verify step — always check numbers, dates, names, and policy claims
  • Using it for tasks where a 30-second human action would be faster

✅ DO THIS

  • Provide context — the file, the brief, the audience, the constraints
  • Iterate; don't just accept the first output
  • Always review numbers, names, dates, and policy claims
  • Treat AI as a fast draft generator, not an answer engine
  • Capture what works so you can replicate it
  • Match the model to the task — fast modes for drafts, reasoning modes for analysis

❌ AVOID THIS

  • Sending AI output without reading it end-to-end
  • Vague prompts with no audience, format, or success criteria
  • Assuming AI can see files or context it hasn't been given
  • Using AI for tasks faster done manually in under a minute
  • Treating numbers, quotes, or citations as verified without checking
  • Defaulting to the slow reasoning mode for every task
