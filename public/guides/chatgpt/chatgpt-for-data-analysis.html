What is ChatGPT for Data Analysis?
Code Interpreter, chart generation, and statistical analysis without writing code

ChatGPT's data analysis capabilities (formerly Code Interpreter, now Advanced Data Analysis) let you upload a spreadsheet or CSV and ask analytical questions in plain English. Behind the scenes, ChatGPT writes Python, runs it, and returns the answer plus a chart.

Best for: anyone who has data and questions but isn't a data analyst — operations, finance, marketing, customer success teams. Replaces the 'can you pull this for me?' ask to the data team for most everyday analysis.

What to Upload
File formats that work
  • CSV — the universal format
  • Excel — multi-sheet works; ChatGPT can navigate sheets
  • JSON — for API exports or nested data
  • Parquet — for larger structured data
  • Compressed archives — ZIPs of multiple files in one go

✅ DO THIS

  • CSV for tabular data — the universal format
  • Excel for multi-sheet workbooks — ChatGPT navigates sheets
  • JSON for nested/structured data — API exports, configuration
  • Parquet for large structured data — efficient at scale
  • ZIP archives for multiple files in one upload
  • Consistent column names — saves prompt-engineering downstream

❌ AVOID THIS

  • Files larger than your tier's limit — gracefully fails but wastes time
  • Files with embedded sensitive data (PII, financial credentials)
  • Files where formatting is messy — clean upstream is faster than instructing ChatGPT to clean
  • Mixing data shapes in one upload (multiple unrelated tables)
  • Forgetting to specify what columns mean in the prompt
  • Trusting the sandbox for production data pipelines — use proper infrastructure

Strong Question Patterns
What to ask
  • Summarise — 'Give me the top-level summary: row count, columns, date range, anything unusual'
  • Aggregations — 'Average order value by region, sorted'
  • Trends — 'How has [metric] changed over time?'
  • Outliers — 'Flag anything that looks like an outlier and explain why'
  • Comparisons — 'Compare this quarter to last quarter on [dimensions]'
  • Forecasts — 'Forecast next 3 months based on this data'
📈
Trend Questions
'How has X changed over [period]?' — surfaces direction and inflection points.
🔢
Aggregation Questions
'Top 5 X by Y' — ranking and grouping queries.
⚠️
Outlier Questions
'Flag anything unusual and explain why' — surfaces what you'd otherwise miss.

The questions that produce useful analysis share a pattern: specific dimension + specific metric + specific time window. 'Average order value by region this quarter' produces a clean answer. 'How's our data looking?' produces vague summary.

For multi-step analysis, chain the questions. Don't ask 'analyse my data and tell me what's going on' — ask 'summarise the data', then 'show me the trends', then 'identify outliers', then 'forecast next quarter'. Each step's output becomes the input for the next.

Analytical questions that consistently work

  • Summarise — 'Give me the top-level: rows, columns, date range, anything unusual'
  • Aggregate — 'Average X by Y, sorted descending'
  • Trend — 'How has X changed over the last [period]'
  • Compare — 'Compare this [period] to last [period] on [dimensions]'
  • Outlier — 'Flag anything that looks like an outlier and explain why'
  • Forecast — 'Forecast next [period] based on this data'

Charts That Land
Asking for the right visual

ChatGPT chooses a chart type by default. For better results, specify:

  • Type — bar / line / scatter / heatmap
  • Axes — X-axis, Y-axis, what's plotted
  • Annotations — call out specific data points
  • Style — 'minimal style, no gridlines'
  • Multiple — 'as a 2x2 grid of charts, one per region'

Specifying charts that look right first time

ChatGPT picks a default chart type based on the data shape. For better results, specify type, axes, and any annotations explicitly. The first chart is often serviceable; the second chart (with explicit specs) is usually publishable.

  • Type — bar / line / scatter / heatmap / box / histogram
  • Axes — what's plotted on X, what's on Y, units
  • Annotations — call out specific data points (mean, threshold, outliers)
  • Style — 'minimal style, no gridlines' or 'use our brand colours'
  • Multiple — 'as a 2x2 grid of charts, one per region'

Limits to Know
Where it falls short
  • Sandbox isolation — code can't reach your DB or external APIs
  • Memory — sandbox resets between sessions; re-upload to continue
  • Reproducibility — same prompt may produce slightly different code; save scripts
  • Production — this is for ad-hoc analysis, not production pipelines
🔬 SHOW THE WORKING
For any statistical claim that will land in a stakeholder document, ask ChatGPT to show the Python code and explain its choice of test. If you can't explain the analysis to a stakeholder, don't ship the analysis. Reproducibility starts with understanding.

Common Mistakes & Fixes
What goes wrong — and how to avoid it

Most AI workflows that 'don't work' fall into one of these patterns. The fix is almost always sharper context and stricter review, not switching models or tools.

  • Treating ChatGPT for Data Analysis as a finished answer rather than a draft to review
  • Vague prompts that don't specify audience, format, or what you want changed
  • Forgetting to give it context — the file, the brief, the constraints
  • Skipping the verify step — always check numbers, dates, names, and policy claims
  • Using it for tasks where a 30-second human action would be faster

✅ DO THIS

  • Provide context — the file, the brief, the audience, the constraints
  • Iterate; don't just accept the first output
  • Always review numbers, names, dates, and policy claims
  • Treat AI as a fast draft generator, not an answer engine
  • Capture what works so you can replicate it
  • Match the model to the task — fast modes for drafts, reasoning modes for analysis

❌ AVOID THIS

  • Sending AI output without reading it end-to-end
  • Vague prompts with no audience, format, or success criteria
  • Assuming AI can see files or context it hasn't been given
  • Using AI for tasks faster done manually in under a minute
  • Treating numbers, quotes, or citations as verified without checking
  • Defaulting to the slow reasoning mode for every task

Suggested Prompts
Ready-to-use prompts you can adapt to your work

These prompts are designed to land in your real work today. Replace the bracketed placeholders with your actual context — the more specific you make them, the better the output. Treat each one as a starting brief, not a finished script.

FIRST-PASS EXPLORATION
Here's [filename.csv]. Give me a first-pass summary: how many rows, what columns, the date range, distribution of the key numeric columns, and anything unusual or suspect in the data.
TREND + FORECAST
In this sales data, show monthly revenue by region over the last 24 months. Highlight any inflection points. Then forecast the next 6 months with confidence intervals. Brief commentary on what's driving the trend.
STAKEHOLDER SUMMARY
Take the analysis we just did. Write a 200-word executive summary: the 3 most important findings, what they mean for the business, and the one question I should investigate further.
