What is Copilot Prompting?

Why your words determine everything Copilot does

A prompt is the instruction you give Copilot in plain English. It's how you tell Copilot what to do, what to work with, how to format the output, and who it's for. Unlike a search query â€” where one or two keywords is enough â€” a good Copilot prompt is closer to a brief you'd give a skilled colleague.

The Prompt Formula

Goal + Context + Source + Expectations â€” the structure behind every great prompt

Microsoft's recommended framework for Copilot prompts has four parts. You don't need all four every time, but the more you include, the better the result. Think of it as filling out a brief before handing work to a colleague.

The Copilot Prompt Formula

What do you want? (Draft / Summarise / Analyse / List / Rewrite)
Context

Expectations
Format, length, tone, audience, level of detail

Common Mistakes & Fixes

What goes wrong with Copilot prompts â€” and how to get better results

â“ Copilot's output is too generic â€” it doesn't feel tailored to my situation.
You're not providing enough context. Add: who the audience is, what the purpose is, and what content Copilot should use. Compare "Summarise this report" (generic) with "Summarise this report for a non-technical board audience, focusing on financial impact and strategic risks" (specific).
â“ Copilot keeps including information I didn't ask for.
Be explicit about scope. Add constraints: "Only use information from this email thread â€” do not add external information." Or: "Focus only on [specific section or topic]." Copilot can over-generate if it lacks a clear scope boundary.
â“ The tone is wrong â€” too formal, too casual, or too robotic.
Specify tone explicitly and give an example if needed. "Warm and professional, like an experienced colleague" is clearer than just "professional." If the first attempt misses, follow up: "Make this warmer â€” it reads too corporate."
â“ Copilot's numbers or facts seem wrong.
Copilot can hallucinate â€” especially statistics and figures not present in the source document. Add the instruction: "Only use figures and facts from the provided content. Do not estimate or add data." Always verify numbers before sharing.
â“ The output is too long / too short.
Give an explicit word or bullet count: "Summarise in under 100 words" or "Provide at least 5 detailed bullet points." Copilot defaults to a medium length â€” you need to specify when you want something significantly shorter or longer.
â“ Copilot Chat can't find the file I'm referencing.
The file must be in OneDrive or SharePoint â€” not your local drive. Confirm the file name spelling matches exactly. If you recently created the file, wait a few minutes for indexing. Also check that you personally have access to that file.

âœ… Do This

  • Specify the audience for every output
  • Set explicit format, length, and tone
  • Reference the source ("from this document / email / transcript")
  • Iterate on responses rather than starting over
  • Verify numbers and facts before sharing

âŒ Avoid This

  • Asking Copilot to reference files stored locally
  • Using sensitive or confidential data in shared chat contexts
