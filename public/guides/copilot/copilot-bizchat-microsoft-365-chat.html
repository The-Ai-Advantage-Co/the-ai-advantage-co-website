What is Microsoft 365 Copilot Chat?
The cross-app Chat surface — free with M365

Microsoft 365 Copilot Chat (formerly Bing Chat Enterprise, briefly called Microsoft 365 Chat) is the standalone Chat experience that lives at m365.cloud.microsoft. It is included free with eligible M365 commercial subscriptions and gives you a single conversation surface that can reference your emails, documents, meetings, and calendar — without bouncing between Word, Outlook, and Teams.

Chat is the right entry point for cross-app work — questions that span more than one file, summaries that pull from your calendar and inbox at once, or queries where you don't know which document holds the answer. For in-document work (drafting a paragraph, building a formula), the in-app Copilot panels are still faster.

💬 TWO TIERS — KNOW WHICH YOU HAVE
Copilot Chat (free with M365) gives you the standalone Chat experience with web grounding. Microsoft 365 Copilot (paid, $18–$30/user/mo) adds the in-app Copilot panels AND tenant-data access in Chat via Microsoft Graph. The Chat URL is the same; what Chat can see depends on your tier.
💬 WHY CHAT BEATS APP-SPECIFIC PANELS
In-app Copilot panels see only the current file. Copilot Chat sees across your tenant (with paid tier). For any prompt that benefits from broader context — multi-file, multi-meeting, multi-conversation — Chat is the right surface, not the in-app panel.

Microsoft 365 Copilot Chat is the most-used Copilot surface in mature deployments. After the initial 'try the in-app panels' phase, most users gravitate toward Chat as their everyday Copilot home — partly because it spans every app, partly because the / command makes file references natural, and partly because it's the surface where agents show up via @-mentions.

For organisations weighing 'where do we start' for adoption, the answer is almost always: Chat. It works for everyone (the free tier covers all eligible M365 users), it teaches the cross-app workflow that's the core Copilot value, and it's the surface that scales as agents are deployed.

Three Chat patterns every user should know

  • Brief me — 'Brief me on tomorrow's meetings' or 'Brief me on /Project Atlas this week'
  • Find me — 'Find the latest version of our pricing doc' or 'Which doc has our refund policy?'
  • Draft me — 'Draft a reply to this email' or 'Draft a status update from these meeting notes'

The Model Selector
Quick Response vs Think Deeper

Chat exposes a model selector at the top. Use Quick Response for everyday drafting, summarising, and rewriting — it's fast and good enough for the majority of tasks. Switch to Think Deeper when the prompt involves analysis, multi-step logic, or trade-offs you actually want it to chew on. The trade-off is latency: Think Deeper takes noticeably longer per response.

🎯 MATCH MODE TO TASK
Drafting an email or summarising a thread? Quick Response. Analysing trade-offs, debugging code, multi-step reasoning? Think Deeper. The 20-30 second wait is the price of harder thinking — pay it when the prompt warrants.

Quick Response vs Think Deeper — when to pick which

Chat exposes a model selector at the top. The choice meaningfully affects both quality and latency. Most users default to Quick Response without thinking about it; the discipline is matching the mode to the prompt.

  • Quick Response — fast, default, good for 80% of everyday tasks
  • Think Deeper — slower, better reasoning for analysis, multi-step logic, code
  • Latency trade-off: Quick is sub-second; Think Deeper is 20-30 seconds typical
  • Cost trade-off: Think Deeper uses more compute; relevant on Enterprise tier
  • Don't default to Think Deeper for short tasks — drains time without quality lift

The / Command — Referencing Files
How to point Chat at specific content

In Copilot Chat, type / and start typing a file name, meeting title, or person — Chat searches your OneDrive, SharePoint, calendar, and contacts.

💡 FREE VS PAID TIER
The / command only reaches your tenant data on the paid tier. On the free Chat tier, / is limited to public web content. If / returns 'no results' for a file you know exists, that's the tier giveaway.
  • / + file name — Reference up to 3 files in a single prompt
  • / + meeting name or date — Reference a specific Teams meeting transcript
  • / + person name — Reference emails, chats, and shared documents with that person
💡 TRAIN THE / HABIT EARLY
Users new to Chat consistently under-use /. The shift happens around week 3 of regular use, when users start instinctively reaching for / before asking the question. Training the / habit explicitly accelerates the shift to week 1 — meaningful adoption lift.

The / command is what makes Copilot Chat materially different from a generic chatbot. Without /, Chat is a clever generic assistant. With /, Chat is an assistant that knows your actual content — your specific documents, your specific meetings, your specific people. The friction-to-value drop from 'generic answer' to 'answer grounded in /Q3 Plan' is the daily Chat experience.

What Chat Is Bad At
When to use an in-app panel instead
  • Editing a specific paragraph in a Word doc — use the in-app panel
  • Building a complex Excel formula on an open sheet — use the Excel panel
  • Generating slides in a specific deck — use the PowerPoint panel
  • Reading a single email and replying — use the Outlook panel

✅ DO THIS

  • Use Chat for cross-app, cross-context, multi-source queries
  • Use Chat with / when you can name the source content
  • Use Chat for synthesis across emails, meetings, docs
  • Use Chat as the entry point for @-mention agents
  • Use Chat for natural-language file discovery
  • Verify outputs that cite specific data — Chat occasionally drifts on quotes/numbers

❌ AVOID THIS

  • Use Chat for editing a specific paragraph in a Word doc — use in-app panel
  • Use Chat for complex Excel formulas on an open sheet — use Excel panel
  • Use Chat for generating slides in a specific deck — use PowerPoint panel
  • Use Chat for reading and replying to a single email — use Outlook panel
  • Assume Chat will know about files you have access to but never opened
  • Treat Chat as a substitute for the in-app surfaces when you're already in one

Agents in Chat
How agents show up in the standalone experience

Copilot Chat is the default surface for the agents your organisation has deployed. You'll see them as @ mentions ('@SalesAgent — what's our pipeline looking like for Q4?'). Agents you build in Copilot Studio appear here automatically, gated by your permissions. Agents inherit your access — they cannot see data you can't see.

🤖 AGENTS ARE JUST SPECIALISED CHATS
Don't think of agents as a separate product — think of them as a Chat preset that's been pre-briefed on a specific domain and given specific tools. Same Chat surface; tighter focus.

Common Mistakes & Fixes
What goes wrong - and how to avoid it
  • Treating Chat like ChatGPT — Chat is at its best when it can see your tenant data
  • Asking generic questions ('write me an email') without referencing files or context
  • Using Quick Response for an analysis prompt — switch to Think Deeper
  • Forgetting that the free tier doesn't see tenant data — / will silently return nothing useful
  • Closing the chat session every time — Chat keeps context across follow-ups, use it

Suggested Prompts
Real starters that show what Chat can do
INBOX TRIAGE
Look through my emails from the last 7 days. Group by topic, flag anything that needs a reply in the next 48 hours, and draft a one-line reply suggestion for each urgent one.
MEETING PREP
Brief me on tomorrow's meetings. For each, give me: who's attending, the agenda or implied topic, any documents I should pre-read, and one suggested question I should ask.
CROSS-DOC SYNTHESIS
Pull together the latest position on /Project-Atlas. Look at meeting recaps from the last 2 weeks, emails on the topic, and the current /Atlas-Plan.docx. Give me the 5 things I most need to know.

See It In Action
A short walkthrough you can replicate today

Monday 8am. You open Copilot Chat and ask: 'Brief me for the week — meetings, anything urgent in my inbox, and any work I committed to last week that I haven't followed through on.' Chat returns a structured brief in 30 seconds: 7 meetings flagged with prep notes, 3 emails marked urgent, and 2 commitments from last Friday's Teams chat that you'd promised to ship Monday. That's your morning standup with yourself, in under a minute.
